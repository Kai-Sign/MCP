Run your own KaiSign node

A Nethermind light client plus KaiSign clear-signing on a server you rent, reachable only from your own devices. Your iPhone wallet points at it; you approve every transaction on your phone.

1Choose the network

The light client trusts this provider once, for its starting point; everything after that is verified on your server. Use one you trust.

2Connect it privately with Tailscale

  1. Install the Tailscale app on your iPhone and sign in.
  2. In the Tailscale admin console → DNS: enable MagicDNS and HTTPS certificates.
  3. Admin console → Settings → Keys → Generate auth key (one-off). Paste it below.

3Activation

One-time activation fee
Advanced
Pin a commit hash you have reviewed for a fully reproducible install.

4Save your private links

Generated in this browser. Store them like a password: the approval link controls your node.

5Create the server

  1. At any VPS provider (Hetzner, DigitalOcean, Vultr, Linode, AWS Lightsail …) create a server with Ubuntu 24.04 LTS, at least 2 vCPU, 4 GB RAM, 40 GB disk.
  2. Find the field called User data / Cloud config / Cloud-init and paste the text below.
  3. Create it. Setup takes about 5–10 minutes; the light client then needs a few more minutes to sync.

6Activate and connect (on your iPhone)

  1. With Tailscale on, open your approval page.
  2. Tap Pay in MetaMask app (or another wallet) and confirm. Your node spots the payment on-chain by itself and unlocks — no account, no card.
  3. The page then shows Connect your wallet: copy the RPC URL into your wallet's network settings.
  4. Send transactions as usual. Each one appears on the approval page — tap Approve & send.
